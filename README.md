# Analasying pulsar data

bash scripts used for project 'Characterising the response of an international LOFAR station using pulsar observations'
for post processing (results published in paper https://arxiv.org/abs/2607.19585 ) --> calling cleaning pipeline for RFI on the archives and updating DM in archives after ad hoc pipeline (see paper Susarla et al. 2025, or https://github.com/saichaitanya99/IE613_timing_pipeline/tree/main)
